# AZ NES Cert Prep — Math + English

Unofficial browser prep system to **ace NES Mathematics (304)** and **NES English Language Arts (301)** for Arizona secondary 6–12, with APK Secondary (052) support alongside your master’s.

## Priority order

1. **Ace each subject exam you will teach** — math and English are independent tracks with the same 85% booking bar
2. Pass APK Secondary (pedagogy + constructed responses)
3. Complete ADE certification paperwork

## Ace standard (do not book early)

Open `ace.html` and drive every gate green **for that subject**:

- Every Foundation Bootcamp and official lesson mastered
- ≥85% accuracy (≥10 attempts) in **every** official domain
- Both half-length forms ≥85%
- Both official-length simulations ≥85%
  - Math: 150 questions, 5 hours
  - English: 150 questions, 3 hours
- ≥70% of that subject’s hard items solved
- Formula / ELA reference sheet + trap guide reviewed

Official passing score is typically a scaled **220**. Your practice bar is higher on purpose.

## How to use

1. Open `index.html` (or run `python -m http.server 8080`)
2. Take the **Foundation Placement Check** for math and/or ELA
3. Follow prerequisite-gated **Learn** → **Practice** → spaced review
4. Live inside **Ace** + timed **Exams** until that subject’s gates flip
5. Use **Formulas** (math sheet + ELA reference) and **Traps** the week you sit

## Obsidian progress backup

Open `notes.html`, choose **Connect Obsidian vault**, and select
`G:\Therapy\educator exams`. The app then autosaves progress to
`Progress/az-nes-progress.json` after lesson checks, practice attempts, and exams.
The browser requires this one-time folder permission before a web page can write
to the vault.
