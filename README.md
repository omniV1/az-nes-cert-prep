# AZ NES Math Cert Prep

Unofficial browser prep system optimized to **ace the NES Mathematics subject exam** (AZ secondary 6–12), with APK Secondary (052) support alongside your master’s.

## Priority order

1. **Ace the math exam** ← everything else is secondary
2. Pass APK Secondary (pedagogy + constructed responses)
3. Complete ADE certification paperwork

## Ace standard (do not book early)

Open `ace.html` and drive every gate green:

- Every Foundation Bootcamp and official math lesson mastered
- ≥85% accuracy (≥10 attempts) in **every** math domain
- Both 75-question half-length forms ≥85%
- Both 150-question, five-hour official-length simulations ≥85%
- ≥70% of hard items solved
- Formula sheet + trap guide reviewed

Official passing score is typically a scaled **220**. Your practice bar is higher on purpose.

## How to use

1. Open `index.html` (or run `python -m http.server 8080`)
2. Take the **Foundation Placement Check**
3. Follow prerequisite-gated **Learn** → **Practice** → spaced review
4. Live inside **Ace** + timed **Exams** until gates flip
5. Use **Formulas** and **Traps** the week you sit

## Obsidian progress backup

Open `notes.html`, choose **Connect Obsidian vault**, and select
`G:\Therapy\educator exams`. The app then autosaves progress to
`Progress/az-nes-progress.json` after lesson checks, practice attempts, and exams.
The browser requires this one-time folder permission before a web page can write
to the vault.
